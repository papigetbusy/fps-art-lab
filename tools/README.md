# Tools
- `sheet.mjs` (to build, task 4 in CLAUDE.md): opens `lab/?view=front|side|three|top&ui=0` in headless Playwright, screenshots each view, puts them next to `references/creatures/<name>/`, adds a silhouette overlay and score, and writes `previews/<name>/sheet.png`.
- `blender/` (optional): headless Blender Python scripts for AO/normal bakes. Never required to run the site.
